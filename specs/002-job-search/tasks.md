# Tasks: Job Search and Home Page List

**Input**: Design documents from `specs/002-job-search/`

**Tests**: **Mandatory** (constitution V). Every task is one red → green → refactor cycle and **one commit**: write the listed tests first, watch them fail for the right reason, write the minimum code, then refactor. Test names reference the requirement or scenario ID they verify (`test_FR022_…`, `test_US1_AS3_…`). Persistence and queue tests run against real PostgreSQL 16 (Testcontainers; start Docker Desktop first). Fakes are allowed only for the LLM, the clock, career-ops and careers-page sources.

**Organization**: tasks are grouped by user story. Stories are in priority order: US2 and US1 (P1) are the first deliverable, then US5, US4, US3 (P2).

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1–US5 from spec.md; Setup, Foundational and Polish tasks have no story label
- Paths: `backend/src/hiretitan/…` (shortened to `hiretitan/…` below), `backend/tests/…`, `frontend/src/…`
- Constraints from data-model.md are quoted in the task text so they are not left to implementation time.
